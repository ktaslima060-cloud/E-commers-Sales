# E-Commerce Sales & Return Analysis Dashboard

An interactive **Power BI** analytics project designed to track, analyze, and visualize e-commerce sales performance, revenue metrics, customer behavior, and product return trends.

---

## 📌 Project Overview

This project provides end-to-end insights into e-commerce operations by combining transaction data (`sales.csv`) and return records (`return_table.csv`) into an interactive Power BI dashboard (`MY BI . Taslima.pbix`).

### Key Highlights & Features
* **Sales Performance Tracking:** Key Performance Indicators (KPIs) for total revenue, order volume, profit margins, and average order value (AOV).
* **Return Rate Analysis:** Identification of frequently returned product categories and reason-based return trends to optimize inventory and minimize losses.
* **Customer & Regional Insights:** Visualizing sales distribution across geographic regions and customer segments.
* **Interactive Dashboard:** Built-in dynamic slicers for date ranges, product categories, and regional filters.
